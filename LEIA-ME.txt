CHESS UP — PROJETO UC7

O Chess Up nesta versão é uma tela demonstrativa estática feita com HTML e CSS, sem JavaScript.

Arquivos principais:
- index.html: redireciona para home.html quando o site é aberto pela raiz.
- home.html: página inicial, tabuleiro ilustrativo, cartões de partidas, desafios e aprendizado.
- sobre.html: página sobre o desenvolvedor, com o mesmo menu responsivo.
- style.css: identidade visual, menu responsivo e layout para diferentes telas.
- logo-chessup.png: logo do projeto.
- avatar.jpg: avatar usado na página Sobre mim.

A tela demonstra:
- Aparência de uma área de jogo e um tabuleiro de xadrez.
- Cards para os modos Rápida, Blitz e Bullet.
- Exemplo visual de histórico de partidas e estatísticas.
- Cartões de desafios e conteúdo introdutório sobre as peças.
- Layout responsivo e menu móvel que abre/fecha com HTML e CSS.

Observação:
Todos os relógios, movimentos, estatísticas e resultados são ilustrativos. Esta versão não executa partidas, não valida movimentos, não salva resultados, não oferece partidas online e não joga contra o computador.

Como testar:
1. Abra home.html com o Live Server ou acesse o site publicado no GitHub Pages.
2. Navegue pelas áreas usando os links do menu.
3. Redimensione o navegador para verificar a responsividade.
4. No celular, toque no menu para abrir ou fechar a navegação.
